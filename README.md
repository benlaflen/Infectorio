Usage Notes:
Commands:
infect-random: infects a random entity in the universe in the same way as an initial patient 0 would be determined
infect-selected: infects the hovered entity with latent infection
manifest-selected: changes the hovered entity to be manifested, regardless of previous infection status
inspect-selected: prints details about the hovered entity's status
infection-overlay: adds a layer to display the current infection status of the map (since spores are otherwise invisible)
